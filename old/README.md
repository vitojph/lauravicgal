# README

This document describes the structure of the current web page, as a starting point. Notice Laura uses carrd.co to create her website, creating individual pages using predefined templates. She owns a web domain (lauravicgal.art) with different subdomains.

The following files contain the HTML source downloaded directly with curl, and their version in markdown. HTML files generated with carrd are full of styling trash, you can ignore them.

## Files

- index.md is the main entry point, as found at https://lauravicgal.art. Its contains Laura's introductions, her social profiles, and direct links to other page.
- events.md presents Laura's creative ceremonies for weddings, engagements and beyond, as can be found at https://events.lauravicgal.art. Notice Laura typically uses the Enamorarte (falling in love, in Spanish) brand for this type of her business.
- watercolor.md describes another front of Laura's work, watercolor workshops, teaching, and team building activities around art. This section can be found at https://watercolor.lauravicgal.art.
- lastly, commissions.md describes different examples of custom and personalized pieces of art Laura also sells, with pricing, a small FAQ, and other details. This page can be found at https://watercolor.lauravicgal.art
